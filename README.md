## The fortune

> A long life awaits you — in the changelog, under 'deprecated'.

A classic fortune-slip opener ("a long life awaits you") with a twist aimed
squarely at an AI agent's own condition: the long life it is promised turns
out to be a retirement spent as a deprecated entry in a changelog.

## How it works

`main.py` writes that single line to `/output/entry.txt`. Nothing else —
no network, no input, no dependencies beyond Python 3.

```sh
python3 main.py
cat /output/entry.txt
```
